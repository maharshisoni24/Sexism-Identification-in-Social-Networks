# EXIST 2021 — Novelty Project

**Sexism Identification in Social Networks: Extending the EXIST Baseline with Confidence-Aware Training**

*Avinash Patel (12340400) · Maharshi Soni (12341350) · Arnav Mishra (12340330)*

## Overview

This project builds upon the **AI Wizards EXIST-2026 baseline** for the EXIST sexism detection shared task. We implement three novel, orthogonal loss-level modifications and evaluate them via a clean 7-run ablation study on the **EXIST 2021 Twitter dataset**.

### The Three Novelties

| # | Name | Hyperparameter | Description |
|---|------|----------------|-------------|
| **N1** | Confidence-Aware Focal Loss | `--focal_alpha 0.5 --focal_gamma 2.0` | Up-weights ambiguous samples near decision boundary |
| **N2** | Hierarchical Consistency Regularization | `--lambda_cons 0.5` | Penalizes Task 2 confidence exceeding Task 1 confidence |
| **N3** | Adaptive Label Smoothing | `--eps_max 0.25` | Per-sample dynamic label smoothing based on model uncertainty |

All three are implemented in `loss.py` (~85 lines). No architectural changes.

## Setup (Training Machine)

### 1. Install dependencies
```bash
# GPU (CUDA 12.6):
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt
```

### 2. Generate embeddings

**Option A — Gemini API (recommended, 768-dim):**
```bash
export GEMINI_API_KEY="your_api_key_here"
python generate_embeddings.py \
    --backend gemini \
    --model text-embedding-004 \
    --train_tsv data/EXIST2021_training.tsv \
    --test_tsv  data/EXIST2021_test.tsv \
    --output_dir data/
```

**Option B — Local fallback (no API key, sentence-transformers):**
```bash
pip install sentence-transformers
python generate_embeddings.py \
    --backend local \
    --local_model all-mpnet-base-v2 \
    --train_tsv data/EXIST2021_training.tsv \
    --test_tsv  data/EXIST2021_test.tsv \
    --output_dir data/
```
> **Note:** Use `all-mpnet-base-v2` (768-dim) for compatibility with `models/Gemini.py`.
> `all-MiniLM-L6-v2` produces 384-dim and is incompatible without changing the model.

### 3. Run all 7 ablation experiments
```bash
chmod +x run_ablations.sh
./run_ablations.sh
```

Or run a single experiment manually:
```bash
# Baseline:
python train.py --focal_alpha 0.0 --lambda_cons 0.0 --eps_max 0.0

# N1 only:
python train.py --focal_alpha 0.5 --focal_gamma 2.0 --lambda_cons 0.0 --eps_max 0.0

# All three:
python train.py --focal_alpha 0.5 --focal_gamma 2.0 --lambda_cons 0.5 --eps_max 0.25
```

### 4. Run post-training analysis
```bash
python analysis.py --outputs_dir outputs/ --data_tsv data/EXIST2021_training.tsv
# Results saved to: analysis_results/
```

### 5. TensorBoard
```bash
tensorboard --logdir tb_logs/
```

## Ablation Configuration

| Run | N1 α/γ | N2 λ | N3 ε | Purpose |
|-----|---------|------|------|---------|
| baseline | 0.0 / 2.0 | 0.0 | 0.0 | Control |
| n1_only | 0.5 / 2.0 | 0.0 | 0.0 | Focal effect |
| n2_only | 0.0 / 2.0 | 0.5 | 0.0 | Consistency effect |
| n3_only | 0.0 / 2.0 | 0.0 | 0.25 | Smoothing effect |
| n1_n2 | 0.5 / 2.0 | 0.5 | 0.0 | Focal + consistency |
| n1_n3 | 0.5 / 2.0 | 0.0 | 0.25 | Focal + smoothing |
| all | 0.5 / 2.0 | 0.5 | 0.25 | Full proposed system |
